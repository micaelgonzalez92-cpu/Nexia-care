# NEXIA DECISION LOG

## Purpose
Turn research and experiments into durable decisions that prevent repeated work.

## Canonical record
Each material decision uses:
1. DECISION
2. DATE
3. CONTEXT
4. EVIDENCE — verified facts only
5. HYPOTHESES AFFECTED
6. ALTERNATIVES CONSIDERED
7. CHOSEN ACTION
8. COST / RISK / REVERSIBILITY
9. RESULT
10. LEARNING
11. NEXT TRIGGER / REVIEW CONDITION

## Rules
- Facts, estimates, hypotheses and recommendations are separated.
- A document is not a result; only verified evidence counts as a result.
- A decision remains active until superseded by newer verified evidence.
- Never repeat an investigation without checking this log first.
- If evidence contradicts a decision, reopen it rather than silently overwrite history.
- No spending or irreversible external action is implied by a decision-log entry.
