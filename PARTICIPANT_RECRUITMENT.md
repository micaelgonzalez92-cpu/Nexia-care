# EXP-001B — Reclutamiento de primer participante

## Objetivo
Conseguir 1 usuario real, sin gasto, para probar NEXIA Care con una De'Longhi Magnifica S / ECAM21-22.110.

## Hipótesis
Un mensaje que no vende, que pide una prueba breve y deja claro que no se requiere comprar nada, reduce la fricción de reclutamiento.

## Mensaje base
> Hola. Estoy probando una herramienta gratuita que ayuda a diagnosticar problemas de cafeteras De'Longhi Magnifica concretas y decir qué hacer después. Busco 1 persona que tenga una Magnifica S/ECAM21-22.110 y quiera hacer una prueba breve. No hay que comprar nada ni dar datos personales. Solo necesito que me cuentes qué problema tiene la cafetera y que pruebes el diagnóstico. ¿Te apetece?

## Criterio de participante
- Tiene una De'Longhi Magnifica S / ECAM21-22.110 o una compatible que permita probar el flujo.
- Tiene un problema, síntoma o duda real.
- Puede completar la prueba sin que Nexia le rescate durante el primer intento.

## Registro mínimo
- Modelo
- Síntoma inicial
- Ruta seguida
- Acción útil alcanzada: sí/no
- Ayuda significativa: sí/no
- Tiempo aproximado
- Fricción observada
- Confianza del usuario
- Resultado
- Aprendizaje

## Regla de evidencia
Opinión < comportamiento < acción completada < disposición a pagar < pago < repetición.

## Coste
0 €.

## Riesgo
Bajo. No se pide compra, pago ni dato sensible.

## Éxito EXP-001B
El usuario alcanza una acción útil sin ayuda significativa.

## Fracaso
Abandona, necesita rescate significativo o el diagnóstico no conduce a una acción útil.

## Siguiente paso
Tras el primer participante, registrar el resultado y repetir hasta 3 participantes antes de declarar patrón.
